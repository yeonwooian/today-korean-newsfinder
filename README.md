# 오늘도국어학원 인스타그램 카드뉴스 자동생성기 (뉴스파인더 통합)

네이버 교육 뉴스 D-1 자동 수집부터 Gemini AI 가변 기획, 1080×1350(4:5) 고화질 카드뉴스 이미지 렌더링, 인스타 캡션 작성, 그리고 텔레그램 자동 보고까지 한 번에 완료하는 모바일 최적화 자동화 파이프라인입니다.

---

## 📱 스마트폰 최적화 웹 대시보드 사용법

### 1. 웹 대시보드 실행
바탕화면의 `Todaykorean.bat` 파일을 더블클릭하거나 터미널에서 실행합니다:
```bash
Todaykorean.bat
```
또는
```bash
.venv\Scripts\streamlit.exe run app.py
```

### 2. 접속 및 로그인
- 브라우저가 열리면 접속 비밀번호 입력 화면이 나타납니다.
- 초기 관리자 비밀번호를 입력하고 로그인합니다.
  *(비밀번호는 Salted SHA-256 해시로 보호되어 코드/화면에 평문으로 노출되지 않습니다.)*

### 3. 수집된 네이버 기사모음 탐색
- 4대 카테고리(`A. 교육정책`, `B. 중고등내신`, `C. 수능·모평`, `D. 입시·대입`)별로 전날(D-1) 기준 발행된 신뢰도 높은 네이버 교육 뉴스가 자동 수집됩니다.
- 날짜를 변경하여 과거 특정 일자의 기사를 검색할 수도 있습니다.

### 4. 원클릭 카드뉴스 생성 & 텔레그램 보고
- 원하는 기사 카드의 **[🚀 게시물 생성]** 버튼을 클릭합니다.
- 파이프라인이 자동 동작합니다:
  1. 기사 본문 스크랩
  2. Gemini AI 카드뉴스 기획 & 인스타 캡션 생성
  3. Playwright 1080×1350 고해상도 이미지 렌더링
  4. **텔레그램(`오늘도_인스타운영`)으로 카드뉴스 앨범과 인스타 캡션 자동 발송**
- 완료 후 웹 화면에 생성된 카드뉴스와 피드 캡션이 표시됩니다.
- 상/하단의 **[↩ 기사모음으로 복귀]** 버튼을 누르면 언제든 기사 목록으로 돌아갈 수 있습니다.

## 📁 통합 프로젝트 구조

```text
오늘도국어 by 제미나이/
├── Todaykorean.bat             # 웹 대시보드 원클릭 실행기
├── app.py                      # 모바일 우선(Mobile-First) 반응형 웹 대시보드
├── config.py                   # 암호 해시, 텔레그램, NCP API 및 4대 카테고리 설정
├── telegram_sender.py          # 텔레그램 송신 전용(Outbound) 보고 모듈
├── telegram_bot.py             # 텔레그램 모듈 안내 및 테스트용
├── main.py                     # CLI & 백엔드 통합 파이프라인
├── scraper.py                  # 네이버 뉴스 기사 정제 추출 모듈
├── ai_planner.py               # Gemini AI 가변 기획 & 인스타 캡션 생성
├── renderer.py                 # Playwright 고해상도(1080×1350) 이미지 렌더러
├── collector/                  # 네이버 교육뉴스 D-1 수집 엔진 (뉴스파인더 통합)
│   ├── __init__.py
│   ├── article_parser.py       # 기사 본문 및 메타데이터 파서
│   ├── naver_api.py            # 네이버 클라우드 플랫폼(NCP) API 모듈
│   ├── naver_web.py            # 네이버 뉴스 전용 크롤러 (차단 방지)
│   └── news_collector.py       # 4대 카테고리 통합 수집기
├── background/                 # 카드뉴스 배경 및 로고 이미지
├── templates/                  # 1080×1350 HTML/CSS 템플릿
├── output/                     # 생성된 카드뉴스 및 캡션 저장소
└── requirements.txt            # 필수 파이썬 라이브러리 목록
```
